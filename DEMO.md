# Demo video script (target 2:50, limit 3:00)

Record the browser window only (no terminal, no editor, no bookmarks bar), at 1280×800 or larger. Use the demo faces, never a real person's photo. The live render takes about 45 seconds; cut the wait and put "sped up" on screen while it is shortened.

Spend: one live render of the Night Editor on demo face A = 6 units. Everything else uses the example tags (0 units). Check the budget line at the top of the page before recording.
